# COPD and periodontal treatment: exploratory economic model

Python implementation of a two-year, China-focused economic model comparing usual
care with scaling and root planing (SRP) plus maintenance. This is a conditional
decision analysis, not a clinical prediction tool or proof of treatment efficacy.

## Contents

- `06_Analysis/`: seven analysis and plotting scripts.
- `07_Evidence/Zhou2014_verified_inputs.json`: extracted published aggregate trial
  inputs, DOI/PMID, table locations and extraction caveats. The publisher PDF is
  not redistributed. No individual patient records are included.
- `reference_results/`: selected saved numerical outputs from the revision model,
  for checking reproduction. PSA draw files and large grids are generated locally.
- `run_all.py`: executes the scripts in order, organizes figures and compares
  outputs with the saved numerical references.
- `requirements.txt`: the numerical/plotting package versions recorded for the
  archived model run (Python 3.12.14). Matplotlib also requires Pillow.

The numbered directories are intentional: scripts use relative paths between
them. Download or clone the entire repository, not an individual script.

## Run

Use a Python 3.12 environment. From the repository root:

```sh
python -m venv .venv
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python run_all.py
```

The PSA uses 50,000 draws per configuration and seed 20261015. There are 12 main
cost-source/maintenance/severity configurations plus conditional sensitivity and
convergence runs. `supplemental_analysis.py` intentionally checks these settings;
do not use a small-draw smoke test as the input to the full reporting pipeline.

Outputs are written under `06_Analysis/results/` and `04_Figures/`; rerunning
overwrites generated files in those directories, not `reference_results/`.
Publication-numbered TIFFs (300 dpi), PNGs and PDFs are placed in figure subfolders.
The legacy plotting scripts also export 1000-dpi TIFFs in the figure root, which
can require appreciable memory and disk space. Word manuscript tables are not
generated by this code package; the numerical CSV outputs are provided instead.

The original individual-script order is:

```sh
python 06_Analysis/analysis.py --n 50000 --seed 20261015
python 06_Analysis/supplemental_analysis.py
python 06_Analysis/zhou2014_analysis.py
python 06_Analysis/threshold_analysis.py
python 06_Analysis/maintenance_schedule_analysis.py
python 06_Analysis/maintenance_roots.py
python 06_Analysis/plot_revision_figures.py
```

`run_all.py` additionally maps the original CEAC, cost-effectiveness plane and
threshold filenames to manuscript Figures 2, 3 and 4, respectively. The model
schematic and structural/one-way plots are Figures 1, S1 and S2. Rendering can
differ slightly across font and plotting environments.

## Interpretation and evidence limits

The default moderate-only scenario assumes no reduction in severe events; this
is a conservative scenario restriction, not evidence of no severe-event effect.
The alternative both-severity scenario assumes a benefit that is not established
by severity-specific trial data. All PSA probabilities are conditional on the
chosen structure and distributions, not probabilities that treatment works.

The trial frequent-exacerbator endpoint is binary. Combining its adjusted odds
ratio with a marginal control risk and using the resulting multiplier on recurrent
event rates is an illustrative, unvalidated extrapolation. Year-specific
deterministic scenarios do not fit a joint PSA or test a time interaction.

China-focused does not mean every parameter is a Chinese empirical estimate:
acute utility decrements include transferred evidence; maintenance resources,
duration, transportability variation and some distributions are assumptions.
Alternative baseline utilities cancel from incremental QALYs under the model's
equal-survival assumptions; that cancellation does not validate the acute losses.
Source definitions and the limits of generalizability should be interpreted with
the accompanying manuscript and supplementary parameter tables.

The published trial is identifiable by DOI
[10.1111/jcpe.12247](https://doi.org/10.1111/jcpe.12247) and
[PMID 24593836](https://pubmed.ncbi.nlm.nih.gov/24593836/). The input file records
the extraction provenance, not a new literature verification performed for this
software release. A source-PDF checksum is retained; the PDF itself is optional
and unavailable in this repository.

## Numerical provenance and portability changes

On 8 November 2026, the complete wrapper was executed with Python 3.12.14,
NumPy 2.3.5, pandas 3.0.1, Matplotlib 3.11.2 and Pillow 13.0.0, using existing
local installations. All 11 saved numerical reference comparisons passed at
`rtol=1e-9, atol=1e-10`. This included the 12 main PSA configurations with
50,000 draws each. A fresh dependency installation was not tested.

The core `analysis.py` is unchanged from the recorded 20 October 2026 model:
SHA-256 `8d576cf0e5ada31a80afe3883f4b864c383c26958966f7b0ef11f2f56a7ee8d6`.
The public packaging removes a local absolute PDF path and internal revision
comment, makes the optional PDF checksum check safe when the PDF is absent, and
moves figure provenance output into the generated results directory. No model
parameter or numerical equation is changed. The wrapper and README are new.

Historical date strings in the original scripts describe the archived revision;
use generated `run_metadata.json` and other timestamped run records for the actual
execution time. Successful numerical checks demonstrate implementation
consistency, not validation of the clinical assumptions.

## Scope of distribution

This package contains code, published aggregate inputs and numerical model
outputs. It excludes manuscripts, reviewer reports, correspondence, publisher
PDFs, credentials, local environments and individual-level patient data.
No software reuse licence has been assigned by this packaging step.
